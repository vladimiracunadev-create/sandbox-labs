# Recruiter Guide

Sandbox Labs demuestra:

- arquitectura de producto orientada a seguridad;
- diseño fail-closed y modelado de políticas;
- Rust de sistemas sin dependencias externas;
- Node.js local con API, jobs, SSE y hardening web;
- trazabilidad mediante evidencia y hashes;
- documentación honesta de límites;
- integración de Linux, WSL2, contenedores, WASI, OCI y microVMs.

Recorrido recomendado: `README.md` → `docs/ARCHITECTURE.md` → `crates/sandbox-runtimes/src/lib.rs` → `control-center/src/jobs.ts` → `tests/scenarios/`.
