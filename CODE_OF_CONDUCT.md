# 🤝 Código de conducta

## Compromiso

Quienes participamos en este proyecto nos comprometemos a que la experiencia
sea libre de acoso para todo el mundo, con independencia de edad, tamaño
corporal, discapacidad, etnia, identidad y expresión de género, nivel de
experiencia, nacionalidad, aspecto, religión u orientación sexual.

## Comportamiento esperado

- Usar un lenguaje acogedor e inclusivo.
- Respetar puntos de vista y experiencias distintas.
- Aceptar la crítica constructiva sobre el trabajo, no sobre las personas.
- Priorizar lo que es mejor para la comunidad y para quien aprende con el repo.
- Mostrar empatía con las demás personas participantes.

## Comportamiento inaceptable

- Lenguaje o imágenes sexualizadas y atenciones sexuales no deseadas.
- Comentarios insultantes o despectivos y ataques personales o políticos.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso explícito.
- Cualquier conducta que sea razonablemente inapropiada en un entorno
  profesional.

## Nota específica de este proyecto

Sandbox Labs trata sobre seguridad. Compartir técnicas de aislamiento y de
evasión con fines educativos es parte del trabajo; usar el repositorio para
distribuir malware, coordinar ataques o publicar exploits dirigidos contra
sistemas de terceros, no. Las cargas de simulación existen para **medir**
controles en un host propio, no para atacar hosts ajenos.

## Responsabilidades

Las personas mantenedoras aclaran los criterios de conducta aceptable y toman
las medidas correctivas apropiadas y justas ante cualquier comportamiento
inaceptable. Pueden eliminar, editar o rechazar comentarios, commits, código,
issues y otras contribuciones que no se alineen con este código, y comunicarán
los motivos cuando proceda.

## Alcance

Este código aplica en todos los espacios del proyecto y también cuando alguien
lo representa en espacios públicos.

## Aplicación

Los casos de comportamiento abusivo, acoso o conducta inaceptable pueden
reportarse en <vladimir.acuna.dev@gmail.com>. Todas las quejas se revisan e
investigan, y reciben una respuesta acorde a las circunstancias. Se respeta la
confidencialidad de quien reporta.
