# Evidencias

Cada ejecución crea un JSON compatible con `schemas/evidence.schema.json`.

Campos principales:

- runtime y política;
- carga ejecutada;
- plan de aislamiento;
- estado;
- salida estándar y errores;
- duración y código de salida cuando exista ejecución real.

Los resultados medidos no deben escribirse en la documentación como si fueran universales. Dependen del host, kernel y runtime.
