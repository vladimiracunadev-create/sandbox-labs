# Flujo AI Code Runner

1. Recibir trabajo y calcular hash.
2. Inspeccionar lenguaje, comandos y dependencias.
3. Clasificar riesgo.
4. Elegir política y runtime compatible.
5. Preparar filesystem efímero.
6. Ejecutar con límites y sin secretos heredados.
7. Recolectar salida y controles efectivos.
8. Destruir el entorno.
9. Firmar o conservar la evidencia según retención.
